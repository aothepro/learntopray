# Welcome to Prayer App 👋

Those that are not fluently familiar with prayers can use the app as an audio guide to perform their prayers. This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

ExpoAudio is still in early stage and doesn't play well in Expo Go, so build a native app using:

iOS:

```bash
npx expo run:ios
```

Android:

```bash
npx expo run:android
```
